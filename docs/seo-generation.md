# Plexudo — Metadata Generation & SEO Audit Methodology

This document provides a technical explanation of how Plexudo generates video metadata (Titles, Tags, and Descriptions), audits metadata quality (Plexudo 50-Point SEO Audit), and integrates external data sources.

---

## 1. Core Principles & Truth in Data

Plexudo adheres to strict data integrity standards:
* **Zero Fake Metrics:** Plexudo never invents keyword search volume, keyword difficulty scores, click-through rate (CTR) predictions, or algorithm ranking probabilities.
* **Transparent Attribution:** Every data element is clearly attributed to its origin:
  - **YouTube Data:** Retrieved directly from the official YouTube Data API v3.
  - **YouTube Search Suggestions:** Real-time query predictions retrieved from YouTube/Google Autocomplete.
  - **AI Suggestions:** Generated by Groq AI large language models based on structured user inputs.
  - **Plexudo Analysis:** Deterministic heuristic metrics computed by Plexudo algorithms.
* **Honest Limitations:** When external data is unavailable or cannot be retrieved, Plexudo returns Data unavailable rather than estimating synthetic numbers.

## 2. Title Generation Methodology

### Objective
Provide video creators with clear, high-intent title angles that accurately represent the video content while matching real audience search behavior.

### Inputs Used
1. Existing video title (if available) or user-provided topic.
2. Extracted primary topic keywords.
3. Relevant niche category context.

### Strategic Angles
The AI title generator produces suggestions across defined strategic frameworks:
1. **Search-Focused:** Optimizes for high-clarity phrasing that directly mirrors common search queries.
2. **Benefit-Driven:** Emphasizes what the viewer gains from watching the video (e.g. learning an outcome or best practice).
3. **Educational / How-To:** Structured tutorial or step-by-step approach.
4. **Curiosity / Story-Driven:** Engages interest with a compelling topic hook without deceptive clickbait.

### Output Structure
Each generated title includes:
* 	itle: The suggested title string (kept within 40–70 characters).
* strategy: The strategic angle applied (e.g., Search-Focused, Benefit-Driven).
* primary_keyword: The core keyword phrase targeted.
* 
eason: An explanation of why the title is structured for that specific topic.

## 3. Tag Generation & Suggestion Methodology

### Objective
Generate relevant, normalized, non-spammy video tags that assist YouTube's search and recommendation indexing.

### Methodology & Data Sources
1. **YouTube Autocomplete Integration:** Queries suggestqueries.google.com to retrieve verified search queries typed by real YouTube users for the given primary topic.
2. **Semantic Expansion via AI:** Identifies long-tail variations, natural phrasing, and niche synonyms without inventing search volume numbers.
3. **Normalization & Deduplication:**
   - Converts all tags to lowercase.
   - Trims whitespace and removes invalid special characters.
   - Eliminates duplicate entries.
4. **Relevance Tiers:** Tags are categorized into clear relevance tiers (YouTube Search, Primary, Long-Tail, Topic Keyword).

## 4. Description Generation Methodology

### Objective
Generate a natural, readable, and comprehensive 3-paragraph YouTube description that contextualizes the video content for viewers and search engines.

### Structural Framework
1. **Paragraph 1 (Hook & Overview):** Introduces the core subject matter of the video clearly.
2. **Paragraph 2 (Key Highlights & Value):** Outlines specific takeaways, techniques, or segments covered.
3. **Paragraph 3 (Call-to-Action & Community):** Encourages viewer engagement (likes, subscriptions, comments) while naturally weaving in contextual terms.
4. **Hashtags:** Appends 3–4 clean, topic-relevant #hashtags.

### Anti-Spam Safeguards
* **No Tag Stuffing:** Plexudo does not generate unnatural comma-separated tag lists or keyword stuffing blocks in descriptions.
* **No Invented Timestamps:** Timestamps are only included when explicitly supplied by the creator.

## 5. Plexudo 50-Point SEO Audit

The **Plexudo 50-Point SEO Audit** is an internal metadata quality rating system developed by Plexudo. It evaluates video metadata against 5 objective optimization factors (10 points each, totaling 50 points):

\\text{Plexudo SEO Score} = S_{\\text{Title}} + S_{\\text{Description}} + S_{\\text{Tags}} + S_{\\text{Consistency}} + S_{\\text{Overlap}}

| Audit Component | Maximum | Criteria Evaluated |
| :--- | :---: | :--- |
| **1. Title Optimization** | 10 pts | Length (ideal 30–70 characters) and presence of substantive topic keywords. |
| **2. Description Depth** | 10 pts | Word count (>80 words) providing sufficient textual context for indexing. |
| **3. Tag Coverage** | 10 pts | Coverage (8–15 relevant tags) for indexing categorization. |
| **4. Keyword Consistency** | 10 pts | Percentage of tags that directly align with terms in the title. |
| **5. Triple Metadata Overlap** | 10 pts | Core keywords present simultaneously across Title, Description, and Tags. |

## 6. What Plexudo Does NOT Claim

To maintain full transparency, Plexudo explicitly states:
1. **Not an Official YouTube Algorithm Tool:** The Plexudo 50-point score is a best-practice metadata audit tool, not an official YouTube metric.
2. **No Guaranteed Rankings:** Metadata optimization improves discoverability; however, YouTube rankings depend on audience retention, click-through rates, viewer satisfaction, and competition.
3. **No Synthetic CTR Claims:** Plexudo does not claim that applying a title or tag will increase CTR by an exact percentage.
